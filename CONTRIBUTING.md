# Contributing

Thanks for considering contributing!

## Getting Started

git clone https://github.com/Arpansharma7/Rag_system.git

cd project

pip install -r requirements.txt

## Running

python app.py

## Coding Style

- Use Black
- Follow PEP8
- Write descriptive commits

## Pull Request Process

1. Fork
2. Create branch
3. Make changes
4. Test
5. Open PR
